# bingshuoguo.github.io

Echo（郭冰硕）的个人站点，使用 [Astro](https://astro.build/) + Tailwind CSS 构建。

**线上地址：** <https://bingshuoguo.github.io>

## 开发

| 命令 | 说明 |
|------|------|
| `npm install` | 安装依赖 |
| `npm run dev` | 本地开发 <http://localhost:4321> |
| `npm run build` | 构建到 `./dist/` |
| `npm run preview` | 本地预览生产构建 |

需要 **Node.js ≥ 22.12**（与 Astro 6 / GitHub Actions 一致）。

## 部署

推送到 `main` 后由 GitHub Actions 自动部署到 GitHub Pages。详见 [`docs/DEPLOY-GITHUB-PAGES.md`](docs/DEPLOY-GITHUB-PAGES.md)。
